1) The doubt being attacked (Momentariness)

Disciple’s argument:

  • Anger changes → love changes → intensity changes → mood changes every moment
  • Therefore the soul must be momentary too

He’s influenced by the Buddhist doctrine of momentariness, but not blindly — he’s observing changes inside himself.

✅ So the Guru doesn’t deny change He clarifies: what changes vs what remains.

2) Verse 68 (core line)

Main statement:

“Ātmā dravye nitya chhe, paryāye palṭāy;
Balādi vay tranyānu, jñān ekne thāy.”

✅ Meaning:

  • As substance (dravya): the soul is eternal
  • As states/modes (paryāya): it keeps changing every moment
  • Childhood–adulthood–old age happen… but one same knower knows all 3

3) Key vocabulary (super high-yield)

Ātmā

= soul

Dravya

= substance (the existing entity)

Nitya

= eternal / constant (as substance)

Paryāya

= state / mode / modification

Palṭāy

= changes / transforms

Balādi vay tranyānu

= the 3 life-stages:

1. Bālya (childhood)

2. Yauvan (adulthood/youth)

3. Vṛddhāvasthā (old age)

Jñān ekne thāy

= knowledge of all these stages belongs to the same one knower

4) The clean philosophical resolution

Guru’s answer is basically:

✅ Soul is not momentary but ✅ Soul’s states are momentary

So both sides get corrected:

  • Buddhists (only change) ✅ partially right
  • Absolute permanence people (only constant) ✅ partially right
  • Truth = both together

5) Why this works: Anekāntavāda (multiple viewpoints)

The Guru’s reply uses Anekāntavāda = multiplicity of viewpoints.

He explains 2 main “nays” (viewpoints):

(A) Dravyārthik nay = viewpoint of substance/existence

  • Focus: “Does it exist continuously?”
  • Answer: Yes → eternal
  • It doesn’t care about childhood/adult/old state

✅ From this view: soul is constant

(B) Paryāyārthik nay = viewpoint of modification/state

  • Focus: “What is changing?”
  • Answer: states change moment to moment

✅ From this view: soul is changing

📌 Both viewpoints are valid but incomplete alone. Together = complete truth.

6) The ultimate Jain definition of Reality (1 liner)

He links it to Tattvārtha Sūtra:

Utpād – Vyay – Dhrauvya

1. Utpād = new state is created

2. Vyay = old state is destroyed

3. Dhrauvya = substance remains constant

✅ This is the true nature of every substance.

So “change” is real, but change is not the whole reality.

7) Best examples used (easy to remember)

Example 1: Ocean and waves

  • Waves keep changing
  • Ocean remains

➡ waves = paryāya ➡ ocean = dravya

Example 2: Gold pot → gold crown

  • Pot-form destroyed
  • Crown-form created
  • Gold remains constant

➡ form changes ➡ substance doesn’t vanish

Example 3 (most powerful): Grinding stone (chakki)

  • Lower stone = stationary
  • Upper stone = rotating

Both statements “it’s moving” and “it’s stationary” are true depending on viewpoint.

📌 Disciple’s mistake = he saw only “rotation/noise” (change) and missed the silent base (existence).

8) The “4 C’s” of soul (quiz material)

He literally gives a memory tool:

✅ Soul remains:

1. Constant

2. Continuous

3. Changeless

4. Consistent

Meaning: the identity as “knower” does not break.

9) The verse’s simple proof (childhood → adulthood → old age)

The argument:

If soul died every moment, then:

  • childhood-soul would be dead
  • a new soul in adulthood would exist
  • so the “new soul” should NOT remember childhood

But we DO remember childhood events.

✅ Therefore: One continuous “knower” exists through all stages.

So even though the body + states change, the same soul carries memory and knowledge continuity.

10) Final one-paragraph summary (perfect revision)

Verse 68 answers the doubt of momentariness by explaining that the soul is eternal as a substance (dravya) but undergoes continuous modification in its states (paryāya). Using Anekāntavāda, the Guru shows that from the dravyārthik viewpoint the soul is constant, and from the paryāyārthik viewpoint it changes every moment. The truth of any substance is utpād–vyay–dhrauvya: new states arise, old states dissolve, but the substance remains. Childhood, adulthood, and old age are different states, yet the same soul knows all three, proving the soul is not momentary.
