0) Where we are in the argument (flow)

By now, the Guru has already shown:

✅ Verse 64–65 conclusion:

  • No association/combination creates the soul
  • Soul is the knower of associations, not the product of association
  • So the disciple’s claim “dehyogthi upje” (soul arises from body) is false

➡ Now Verse 66 completes it:

✅ If the soul is not created, then it cannot be destroyed.

1) Verse 66 (the exact line)

Verse:

“Koi sanyogothi nahi, jeni utpatti thay;
Nash na teno koima, tethi nitya saday.”

Word meanings

  • Koi sanyogothi nahi = not from any association / union / combination
  • Jeni utpatti thay = whose origination/creation happens
  • Nash na teno koima = it does not get destroyed into anything
  • Tethi = therefore
  • Nitya saday = eternal, always existent (always = literal; eternal = implied)

2) Short meaning (one-liner)

That which is not born from any combination can never be destroyed by separation; therefore it is eternal.

3) Guru’s core logic (universal law)

Universal law stated here:

✅ Whatever is created can be destroyed. ✅ Whatever is not created cannot be destroyed.

So:

  • If a thing is made by “joining parts,” it can break by “separating parts”
  • But the soul is not a joined product → so it cannot break

4) The disciple’s idea gets reversed

Disciple’s formula was:

Created by body-contact → destroyed by body-separation

Guru destroys it using the same structure:

  • If soul is not created by association, then there is no reason it should end by dissociation.

✅ No “joining” happened → so no “breaking” can destroy it.

5) The key upgrade in the soul-teaching

He says the Guru’s teaching progresses in steps:

Step 1 (First Fundamental Truth):

  • Soul is distinct from body (different substance)

Step 2 (now in 66):

  • Soul is permanent + indestructible
  • Distinct and unchanging in its nature (not talking about modes, but intrinsic nature)

6) “Natural substance” idea (VERY important)

He explains what “uncreated” really means:

✅ If it can’t be produced by conditions/associations, then it is sahaj swaroop = a natural, self-existent substance.

Like matter is natural substance, soul is also natural substance.

So he challenges:

“Give me one good reason why it should get destroyed.”

And the point is: Products disintegrate. Natural substances don’t vanish.

7) The Fevicol example (created object breaks)

He repeats the same example from earlier:

  • Two objects glued = a product of association
  • Fevicol dries → bond breaks → object “gets destroyed”

Then he asks the killer question:

“Soul is a combination of what?”

Hydrogen? Nitrogen? Copper?

Since you can’t name any “ingredients,” you can’t claim it is a product.

✅ No ingredients → no production → no destruction.

8) Pot example = form destroyed, substance not destroyed

He explains destruction properly:

Pot is created → pot can break

But what actually “dies”?

✅ The form “pot” ends ❌ the substance (clay particles) never disappears

So:

  • Form is destroyed
  • Substance remains (in another form)

Then he applies it to the soul:

✅ Soul is a substance with knowingness So it is not “a form made from parts,” hence it cannot end like a pot.

9) “Knowingness” vs “Consciousness” (nice nuance)

He clarifies a language distinction:

  • Consciousness = when discussing nature in philosophy/metaphysics
  • Knowingness / witnessing = when teaching meditation (as a verb/practice)

But meaning is the same: ✅ Soul’s essential nature = knowingness/consciousness And the soul cannot drop this nature and become inert like:

“I’m tired of consciousness, I’ll become unconscious.” That’s psychology/mood. This verse is metaphysics.

Everlasting Undying Unending Endless Timeless Immortal
